# 🚀 Petualangan Bilangan

Game interaktif operasi bilangan bulat untuk **Matematika Kelas 7** (Kurikulum Merdeka).

## Cara main
1. Buka `index.html` di browser (bisa offline).
2. Pilih operasi: penjumlahan, pengurangan, perkalian, pembagian, atau campuran.
3. Pilih level: Mudah, Sedang, atau Sulit.
4. Jawab 10 soal — kumpulkan skor, jaga 3 nyawa, dan kejar bonus beruntun! 🔥

## Fitur
- ⏱️ Timer per soal + bonus kecepatan
- ❤️ Sistem nyawa
- 📝 Review soal yang salah di akhir permainan
- 🔊 Efek suara (bisa dimatikan)
- 📱 Responsif untuk HP dan laptop

Dibuat untuk pembelajaran materi bilangan kelas 7.
